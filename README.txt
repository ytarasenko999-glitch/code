CODE — тестова версія сайту

app.html    — розмітка й стилі сайту; сторінки віддає api/page.js з SEO-даними з адмінки
app.js      — увесь код застосунку (підвантажується з defer)
i18n/tr-*.js — переклади (кожна мова окремим файлом, вантажиться лише для своєї мови; оновлює tools/i18n-merge.py)
prerender/  — знімок стартового екрана для миттєвого першого показу (оновити: NODE_PATH=$(npm root -g) node tools/prerender.js після змін стартового екрана)
favicon.svg — іконка вкладки

Що працює: матриця, сумісність, роки, енергія дня, карта здоров'я, довідник,
шпаргалка, кабінет (зберігається в браузері), PDF, вибір карт Таро.
Що ще не підключено: ШІ-трактування Таро (потрібен ключ Claude API і серверна функція),
справжні акаунти, оплати.
